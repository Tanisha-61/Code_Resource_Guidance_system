# Project Overview

## Problem
Students often struggle to find quality coding resources that match their language, topic, experience and preferred format.

## Objective
Build a central resource guide that allows students to search, filter, save and discover relevant learning material.

## Modules
1. Authentication and user management
2. Resource catalogue and search
3. Recommendation/filtering
4. Bookmark management
5. Administrator resource management

## Recommendation approach
The first version uses transparent filter-based matching. The selected language, level, resource type and search keywords narrow the resource catalogue. This is simple to explain, test and extend later with more advanced recommendation techniques.

## Future scope
- Personalized learning roadmaps
- User progress tracking
- Rating and reviews
- AI-assisted recommendations
- Analytics dashboard
